# SaaS Namy

## Painel do CLIENTE (use este)

Pasta: **[client-panel/](client-panel/)**

```bash
cd saas/client-panel
npm install
npm start
```

Cliente abre: **http://localhost:3847**

Telas: Login, Status, WhatsApp, Shopee, Anuncios, Conta.

O cliente **nao** usa terminal.
